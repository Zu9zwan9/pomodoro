# Pomodoro

A Pomodoro timer with a built-in task list, in plain HTML, CSS and JavaScript. No build step and no dependencies.

- 25-minute focus sessions, with short and long breaks between them
- **Next** skips to the next stage, **Reset** restarts the current one
- Add tasks and tick them off while the timer runs

## Run it

Open `index.html` in a browser.

## Code

- `controller.js`: timer loop, stage switching and the task list
- `task.js`: the timer's state object
- `constants.js`: session lengths
